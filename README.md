# Tach workspace fork

Adds `workspace_modules = true` to enforce module dependencies and public interfaces across uv workspace packages. Configure `source_roots` explicitly; member discovery is not automatic.

CI tests and publishes Linux x86_64/arm64 wheels as [GitHub releases](https://github.com/na47io/tach/releases). No macOS builds.

See [upstream Tach](https://github.com/tach-org/tach) for installation, documentation, and everything else. Tracks [upstream issue #942](https://github.com/tach-org/tach/issues/942).
